# Pilkades2026 - SaaS Tabulasi Suara Real-Time

Sistem tabulasi suara Pilkades Serentak dengan fitur:
- Login Saksi per TPS
- Input suara real-time
- Dashboard admin dengan grafik live
- Multi-tenant SaaS (per kandidat)
- Export data per TPS

## Demo
Buka index.html di browser atau deploy ke GitHub Pages

## Akun Demo
- Kode Saksi: KANDIDAT-01
- Kode Admin: ADMIN-01
- Desa: Sriamur

## Teknologi
- HTML5 + Tailwind CSS + Chart.js
- localStorage + BroadcastChannel (real-time sync)
- 100% client-side, no backend needed

## Cara Pakai
1. Admin login, tambah kandidat & saksi
2. Saksi login, input suara dari TPS
3. Dashboard admin update otomatis
